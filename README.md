# Lacius — entrega do redesign

Referência visual completa para avaliação e integração pela equipe da empresa. Proposta não oficial, sem backend ou ligação com os dados reais do produto. Inclui HTML, CSS, JavaScript, logo PNG e quatro fotos locais do site original, utilizados com autorização informada por quem solicitou a proposta. O envio não concede uma licença geral sobre a marca ou as imagens.

## Usar no Codex

Anexe este repositório ao ambiente do Codex ou permita que ele o clone. Só colar um link não garante acesso: o ambiente precisa conseguir ler o GitHub e também o projeto que receberá o visual.

Copie o pedido abaixo e inclua o link deste repositório:

> Importe o visual completo desta referência para a landing page do nosso projeto. Primeiro leia AGENTS.md, README.md, index.html, styles.css e app.js. Reutilize todos os arquivos de assets/. Preserve o layout responsivo, os textos, o logo PNG e os dois seletores funcionais, adaptando à tecnologia do projeto atual sem substituir o sistema, suas rotas ou sua autenticação. Conecte os botões aos nossos fluxos reais existentes. Não apenas se inspire: reproduza a composição e os estilos da referência. Execute e compare no navegador em desktop e celular. Informe qualquer diferença ou impedimento antes de declarar a integração concluída.

## Executar a referência

Não precisa instalar dependências. Abra index.html ou, na pasta do repositório, execute:

```sh
python -m http.server 8787 --bind 127.0.0.1
```

Acesse http://127.0.0.1:8787.

## Conteúdo

- index.html: página completa e textos.
- styles.css: visual, cores e adaptação às telas.
- app.js: seletores de módulos e exemplos, menu e acessibilidade.
- assets/: todas as imagens necessárias, sem hotlink.
- AGENTS.md: instruções de importação para agentes como o Codex.

Os módulos começam em Documentos e equipe; os exemplos começam em Documento revisado. A seleção mostra somente o conteúdo correspondente. As perguntas usam elementos nativos de expansão. Não há coleta de dados, formulário de cadastro, cookies, dependência de CDN ou build.

## Limites

Esta entrega importa a apresentação, não implementa o SGQ. Os exemplos são ilustrativos e não representam capturas da interface real nem automações garantidas. Condições comerciais e integrações técnicas devem ser confirmadas pela empresa. Preserve o aviso de proposta no rodapé durante a avaliação.
