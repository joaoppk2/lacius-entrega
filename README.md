## Importar com o Codex

Disponibilize este repositório e o projeto de destino no Codex. Envie:

> Leia AGENTS.md e importe o visual completo desta referência para a landing page do nosso projeto. Preserve os textos, imagens, layout responsivo e seletores. Adapte à tecnologia existente sem substituir rotas, autenticação ou funções do sistema. Teste no navegador em desktop e celular.

O repositório inclui todo o HTML, CSS, JavaScript e imagens. As instruções técnicas estão em AGENTS.md.

Proposta não oficial de apresentação, sem backend ou acesso aos dados do produto. Exemplos ilustrativos; condições comerciais e integrações devem ser confirmadas pela empresa. Marca e imagens não possuem licença geral de redistribuição.
